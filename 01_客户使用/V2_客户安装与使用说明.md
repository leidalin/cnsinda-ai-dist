# DL评论助手 V2 客户安装与使用说明

## 一、产品用途

DL评论助手用于已授权账号的文章评论检测、扫描记录管理以及人工启动的评论、点赞和收藏辅助操作。

当前正式支持：

- CSDN
- 知乎
- 今日头条
- 百家号
- 网易

其他网址会标记为“第三方平台（等待开发）”，不会执行扫描或互动。
第三方链接仍会进入本次结果和扫描记录，便于汇总、复制和导出。

本产品仅供测试、学习及已授权账号管理使用。不得用于刷量、骚扰、绕过验证码或平台安全验证，也不得用于违法违规用途。

## 二、目录说明

客户只需要使用 `01_客户使用`：

- `浏览器插件`：在 Chrome 中加载的完整扩展目录，全部功能都在这里。
- `V2_客户安装与使用说明.md`：本说明。

`02_完整源码` 和 `03_需求与维护文档` 供开发维护使用，普通客户不需要打开。

## 三、首次安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `01_客户使用\浏览器插件` 文件夹。
5. 安装完成，直接点击插件图标使用；没有任何额外安装或配置步骤。

## 四、基本使用

### 批量检测

1. 点击插件图标进入数据中心。
2. 在“批量检测”中每行粘贴一个 URL。
3. 点击“开始检测”。
4. 检测最多双并发，新页面启动至少间隔 2.5 秒，可随时停止；已完成结果会保留。

### 扫描记录

- “刷新列表”只重新读取本地数据库，不会访问网页。
- “重新扫描”或“重新扫描全部”才会打开网页并检测最新评论、点赞和收藏状态。
- 可按评论数量排序、设置低评论警戒线、导出全部或低于阈值的记录。
- “更多 → 删除此记录”只删除该条扫描记录，不删除评论历史。
- 404 或失效链接会标红并归零。

### 评论模式

知乎、今日头条和百家号发布评论时，插件会在独立操作窗口中运行，以满足平台编辑器的真实输入要求；窗口不会主动抢占用户当前页面，任务结束后自动关闭。请勿在评论执行过程中手动关闭操作窗口。

在“智能补齐 → 评论生成模式”中二选一：

1. `AI 评论`：读取文章内容，使用已配置的大模型生成一条相关评论。
2. `无 Key 模板`：不调用大模型，从客户保存的评论模板中选择一条。

无 Key 模板规则：

- 最多保存 500 条。
- 每条模板必须使用英文分号 `;` 分隔。
- 支持“按顺序”和“随机抽取”。
- 随机模式会尽量避免连续抽到同一条。

智能补齐会先将同一篇文章连续补到目标评论数，再处理下一篇；每次评论随机间隔 1.5-4 秒，任务期间可以随时停止。若平台未确认发布、未登录或触发风控，会停止该文章剩余次数，避免重复发布。

### AI Key

- Key 在插件“智能补齐”页面配置。
- 插件只显示“已填写/未填写”，不会回显明文。
- 选择记住后，Key 保存在当前 Chrome 扩展的本地存储中；卸载扩展前应先加密导出配置。
- Key、Cookie、Authorization、备份密码不会写入操作日志。

### 配置备份

账号设置、警戒线、评论模式、模板选择方式、最多 500 条模板和 AI 配置可加密导出为 `.dlconfig`，更新插件前建议备份。

### 导出诊断日志

进入“账号设置 → 问题排查”，点击“导出诊断日志”，Chrome 会下载一个 JSON 文件。该文件包含插件内部保存的脱敏操作日志和问题日志，不包含 API Key、Cookie 或 Authorization。

## 五、平台说明

- 网易只统计评论，不检测或执行文章点赞和收藏。
- 网易“跟帖”和“参与”都计入评论，并按评论 ID 去重。
- 未登录、账号不一致或账号状态未知时，软件会停止互动并提示客户检查。
- 出现验证码、操作频繁或安全验证时，任务会停止，不会绕过平台验证。

## 六、更新与卸载

更新时保持 `浏览器插件` 文件夹路径不变，覆盖文件后在 `chrome://extensions` 点击“重新加载”。这样更容易保留扩展 ID 和本地扫描记录。

插件扫描记录保存在 Chrome IndexedDB 中；AI 配置、任务状态和排障日志保存在扩展本地存储中。卸载扩展会清除这些数据，卸载前请先加密导出配置和需要保留的数据。
