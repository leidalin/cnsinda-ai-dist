# DL评论助手 V2

这是 DL评论助手的客户可用自动化 发行包，当前版本支持 CSDN、知乎、今日头条、百家号、网易和搜狐。其他链接会记录为第三方平台，不会执行互动操作。
支持 点赞 收藏 评论 查询 截图

纯 **Chrome Manifest V3 扩展**：不需要安装客户端、EXE、本地服务或注册后台，`chrome://extensions` 加载目录即可使用。

## 安装

1. 下载并解压 ZIP。
2. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择解压后的 `01_客户使用/浏览器插件` 文件夹。
5. 点击插件图标进入数据中心即可使用，不需要安装客户端或注册后台服务。

## 当前版本

- 版本：2.0.3
- 构建日期：2026-10-20
- 智能补齐：同一篇文章连续补到目标数，再处理下一篇。
- 评论间隔：随机 1.5–4 秒，可随时停止。
- 后台任务：使用独立操作窗口和可复用标签页，不依赖用户当前查看的页面。
- 评论历史：每次评论独立记录，支持分页、核验和存档关联。

### 2.0.3 主要修复

- **百家号重复评论**：账号识别不再把站点导航文案（“到百度首页”等）当成当前账号；本轮已点过“发表”的链接，复扫数量未同步时不再自动重复补发。
- **「导入并快速检测」失效**：补齐缺失的 `importAndStartDetection`，先落库再按导入前的分类结果启动检测。
- **网易检测**：改为接口通道（`comment.api.163.com`），不再依赖页面渲染评论区，未激活的后台标签页也能扫到。
- **搜狐翻页**：改用 `/wap/api/comments/pages`（`/comments/load` 传 `page_no` 不会真正翻页）。
- **诊断日志**：系统设置新增「诊断日志与问题反馈」，一键导出完整 JSON。
- 其余交互、截图与扫描细节见[维护说明](./03_需求与维护文档/DL评论助手_维护说明.md)变更记录。

本项目仅用于合法、合规的测试、学习和已授权账号管理。使用时请遵守相关法律法规、平台规则，并人工复核发布内容。
