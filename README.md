# DL评论助手 V2

这是 DL评论助手的客户可用自动化  发行包，当前版本支持 CSDN、知乎、今日头条、百家号、网易和搜狐。其他链接会记录为第三方平台，不会执行互动操作。
支持 点赞 收藏 评论 查询 截图

## 安装

1. 下载并解压 ZIP。
2. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择解压后的 `01_客户使用/浏览器插件` 文件夹。
5. 点击插件图标进入数据中心即可使用，不需要安装客户端或注册后台服务。

## 当前版本

- 版本：2.0.0
- 构建日期：2026-08-24
- 智能补齐：同一篇文章连续补到目标数，再处理下一篇。
- 评论间隔：随机 1.5–4 秒，可随时停止。
- 后台任务：使用独立操作窗口和可复用标签页，不依赖用户当前查看的页面。
- 评论历史：每次评论独立记录，支持分页、核验和存档关联。
